# SKR Brain Challenge

แพลตฟอร์มเกมฝึกคิดสำหรับผู้เรียน: เล่นด้วยชื่อเล่น, คะแนนรวมและคะแนนรายวิชา, และพื้นที่จัดการสำหรับครู

## โครงสร้างเริ่มต้น
- `brain-challenge/index.html` — เว็บต้นแบบ responsive พร้อมเกมตัวอย่าง 8 หมวดหมู่
- `supabase/schema.sql` — โครงสร้างฐานข้อมูลและ Row Level Security สำหรับระบบจริง

## ทดลองใช้งาน
เปิด `brain-challenge/index.html` ในเบราว์เซอร์ หรือเปิด GitHub Pages จากโฟลเดอร์ที่ตั้งค่าไว้
- ใส่ชื่อเล่นแล้วเลือกหมวดหมู่
- เล่นคำถามตัวอย่างและสะสมคะแนน
- สลับดูอันดับรวม/อันดับรายวิชา
- พื้นที่ครูต้นแบบใช้รหัส `teacher-demo`

## ข้อจำกัดของรุ่นต้นแบบ
รุ่นนี้เก็บข้อมูลใน localStorage ของเบราว์เซอร์เท่านั้น คะแนนและคำถามจึงยังไม่แชร์ข้ามอุปกรณ์หรือผู้เล่น และรหัสครูเป็นเพียงทางเข้าทดสอบ **ห้ามใช้เป็นระบบรักษาความปลอดภัยจริง**.

## ขั้นตอนก่อนเปิดใช้จริง
1. สร้าง Supabase project
2. รัน `supabase/schema.sql` ใน SQL Editor
3. ตั้งค่า Supabase URL และ anon key ในแอป (ห้ามใส่ service-role key ใน frontend)
4. เปิดใช้ Supabase Auth สำหรับครู และกำหนด role ครู/ผู้ดูแลผ่านตาราง profiles
5. ย้ายการบันทึกคะแนนและคำถามจาก localStorage ไปยัง Supabase พร้อมตรวจสอบ RLS
6. เปิด GitHub Pages หรือ deploy ไปยัง Vercel
